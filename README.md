# SIGI — distribución institucional

Repositorio privado para entregar versiones instalables de SIGI a instituciones autorizadas.

Este repositorio contiene únicamente:

- una instantánea versionada de la plataforma;
- el instalador para Ubuntu;
- manuales de despliegue y operación;
- paquetes Docker y checksums publicados como GitHub Releases.

No contiene datos de instituciones, credenciales, respaldos, configuraciones operativas ni el historial interno de desarrollo.

## Descargar

Consulte la sección [Releases](https://github.com/Restoration-Team-FAO/SIGI-Distribution/releases) y descargue la versión autorizada.

La versión inicial disponible es `v2.1.3`. Siga el archivo `MANUAL-INSTALACION-LOCAL.md` incluido en la Release.

## Acceso

El acceso es de solo lectura y se concede individualmente. No redistribuya los paquetes ni comparta credenciales de GitHub.

## Soporte

Para reportar un incidente, indique la versión mostrada por `/api/version`, el servicio afectado y la salida de `docker compose ps`. Nunca adjunte archivos `.env`, contraseñas, tokens o respaldos de base de datos.
